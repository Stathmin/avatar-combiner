# Аватар — объединитель 4 планшетов

Объединяет четыре 96-луночных планшета в один 384-луночный для Bio-Rad CFX Manager.

## Структура

- `src/` — исходники пайплайна, интерфейса и тестовый Excel-файл.
- `app/` — исходная готовая сборка из архива.
- `ТЗ аватар.docx` — исходное задание.
- `*_*.zip` — исходные архивы.

## Запуск

Зависимости и запуск — через `uv`:

```bash
uv sync
uv run python src/run_pipeline.py
```

При запуске в терминале открывается лёгкий интерфейс без сторонних библиотек.
Интерфейс работает на стандартной библиотеке Python: без Textual, Rich, pandas,
numpy и openpyxl.

### Быстрые клавиши

| Клавиша | Действие |
|---|---|
| `R` / `Enter` | запустить объединение |
| `D` | список папок `Результат N` |
| `O` | открыть последний результат |
| `C` | настройки и `config.json` |
| `H` | помощь (EN/RU) |
| `L` | переключить язык |
| `Q` | выход |
| `↑` / `↓` | выбор в списке результатов |
| `B` / `Esc` | назад |

Справка `H` показывает английский и русский текст рядом на широком терминале.

### Запуск без интерфейса

```bash
uv run python src/run_pipeline.py --no-ui
```

Флаги: `--ui`, `--no-ui`, `--lang en|ru`, `--version`, `--help`.

## Результаты

При каждом запуске создаётся новая папка `Результат N` рядом с `config.json`.
В неё записываются все результаты: CSV планшетов, метаданные, объединённый CSV,
пивот-таблица и `combined_384_plate_ids.txt`.

Повторный запуск создаёт `Результат 2`, затем `Результат 3` и так далее.
Корень программы при этом остаётся чистым.

## Настройка

Названия Excel-файла и листов задаются в `src/config.json`.


## Сборка exe

Сборка выполняется только на Windows:

```bash
uv sync --group build
cd src
uv run python build_binary.py
```

Готовый файл появится в `src/dist/`. Runtime-зависимостей нет, поэтому сборка
получается заметно меньше прежней (openpyxl больше не входит в exe).

Если установлен `upx`, скрипт сборки включает сжатие автоматически. UPX может
вызывать ложные срабатывания антивируса. На Linux onefile включает libpython,
поэтому размер Linux-бинарника не равен размеру Windows-exe.
