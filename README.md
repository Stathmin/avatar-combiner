# Аватар — объединитель 4 планшетов

Объединяет четыре 96-луночных планшета в один 384-луночный для Bio-Rad CFX Manager.

## Структура

- `src/` — исходники пайплайна и тестовый Excel-файл.
- `app/` — исходная готовая сборка из архива.
- `ТЗ аватар.docx` — исходное задание.
- `*_*.zip` — исходные архивы.

## Запуск

Все зависимости и запуск — через `uv`:

```bash
uv sync
uv run python src/run_pipeline.py
```

При каждом запуске создаётся новая папка `Результат N` рядом с `config.json`.
В неё записываются все результаты: CSV планшетов, метаданные, объединённый CSV,
пивот-таблица и `combined_384_plate_ids.txt`.

Повторный запуск создаёт `Результат 2`, затем `Результат 3` и так далее.
Корень программы при этом остаётся чистым.

## Настройка

Названия Excel-файла и листов задаются в `src/config.json`.

## Проверка

```bash
uv run pytest
```

## Сборка exe

Сборка выполняется только на Windows:

```bash
uv sync --group build
cd src
uv run python build_binary.py
```

Готовый файл появится в `src/dist/`.
